## 1. Overview & Lab 3 Extension Summary
This project builds directly upon the working Dining Meal Booking application from Lab 1 and Lab 2 to satisfy the **Distinction Extension** requirements. Rather than creating a new application, Lab 3 extends the existing `Student`, `MealBooking`, and application runner classes by introducing an advanced object-oriented hierarchy featuring:
* Encapsulation using private fields (`#`);
* Class inheritance (`extends`) and constructor chaining (`super()`);
* Specialized derived dining account types (`RewardsDiningAccount` and `CreditDiningAccount`);
* Method overriding and polymorphism;
* Transaction history tracking and simulated method/constructor overloading.
