## Description
This Node.js console application allows students to book dining meals. It demonstrates classes, objects, constructors, private fields, getters/setters, validation, controlled methods, and error handling.

## Files
- `MealBooking.js` — defines the MealBooking class with private fields and methods.
- `DiningApp.js` — console application that collects input, validates, stores bookings, and displays receipts.
